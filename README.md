# AntonBronnfjell/homebrew-tap

Homebrew formulae for [AntonBronnfjell](https://github.com/AntonBronnfjell)'s tools.

```bash
brew install AntonBronnfjell/tap/html-design-system
```

| Formula | Command | What it is |
|---|---|---|
| `html-design-system` | `ds` | CLI of the [html-design-system](https://github.com/AntonBronnfjell/tooling-agent-skill-markdown_html-design-system) agent skill: build, check and document complete HTML/CSS design systems (`ds init`, `ds build`, `ds serve`, …). Run the line `brew` prints after install to add the skill to your AI agents. |

Formulas are updated automatically when a release is published in the source repo (its `homebrew` workflow), and this repo's CI installs and tests each change on macOS and Linux.
